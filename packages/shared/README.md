# Shared Package

Shared TypeScript types and utilities for all teams.

## Contents
- `types/` - Shared interfaces (Task, Report, Technician, Runbook)
- `utils/` - Common utility functions
- `constants/` - Shared constants

## Usage
```typescript
import { Task, Report } from '@xp-compressor/shared';
```

## Development
```bash
npm run build
npm run watch  # Auto-rebuild on changes
```
